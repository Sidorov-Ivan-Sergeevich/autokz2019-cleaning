# Продажи автомобилей в Казахстане (январь–сентябрь 2019)

Курсовой проект «Предподготовка и анализ данных»: очистка данных и анализ позиции автоцентра «Меркур Авто».

## Файлы
- [Отчёт](Сидоров%20И.С.%20Отчёт%20продажа%20авто.docx) — Word-документ, открывается после скачивания
- [clean_autokz.py](clean_autokz.py) — скрипт очистки
- [autokz2019_analysis.ipynb](autokz2019_analysis.ipynb) — ноутбук с EDA и анализом
- [autokz2019_clean.csv](autokz2019_clean.csv) — итоговый очищенный датасет

## Запуск
python clean_autokz.py autokz2019.csv autokz2019_clean.csv
